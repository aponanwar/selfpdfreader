# Self PDF Reader 📚

একটি আধুনিক, দ্রুত এবং পূর্ণাঙ্গ মোবাইল PDF Reader অ্যাপ্লিকেশন।

## 🌟 ফিচারসমূহ (Features)

1. **ডিভাইস স্টোরেজ ব্রাউজিং:** ফোনের মেমোরি থেকে যেকোনো PDF ফাইল সহজে নির্বাচন এবং ওপেন করার সুবিধা (`expo-document-picker`)।
2. **মসৃণ PDF রেন্ডারিং (Smooth Viewer):** Mozilla PDF.js দ্বারা পরিচালিত হাই-রেজোলিউশন পেজ রেন্ডারিং ও পিঞ্চ-টু-জুম।
3. **নাইট মোড ও সেপিয়া মোড (Night & Sepia Modes):**
   - **Light Mode:** স্বাভাবিক দিনের আলোয় পড়ার জন্য।
   - **Dark / Night Mode:** রাতে চোখের ক্ষতি ছাড়া পড়ার জন্য ক্যানভাস ইনভার্ট মোড।
   - **Sepia Mode:** বইয়ের কাগজের মতো উষ্ণ ও আরামদায়ক রিডিং মোড।
4. **স্মার্ট রিডিং হিস্ট্রি ও রিসেন্ট ফাইলস:**
   - শেষ যে পেজে পড়া থামানো হয়েছে তা মনে রাখা এবং শতকরা হিসেব (Progress Bar) দেখানো।
   - ফাইল সাইজ এবং লাস্ট ওপেন করার সময় প্রদর্শন।
5. **বুকমার্ক সিস্টেম (Bookmarks):**
   - যেকোনো গুরুত্বপূর্ণ পেজ এক ট্যাপে বুকমার্ক করা।
   - বুকমার্ক লিস্ট থেকে সরাসরি যেকোনো পেজে জাম্প করা।
6. **টেক্সট-টু-স্পিচ (TTS Audio Reader):**
   - PDF-এর পেজের লেখা স্বয়ংক্রিয়ভাবে অডিও আকারে পড়ে শোনাবে (`expo-speech`)।
   - প্লে, পজ, স্টপ এবং স্পিড পরিবর্তন (0.75x, 1.0x, 1.25x, 1.5x)।
7. **টেক্সট সার্চ (In-Document Search):** PDF-এর ভেতরের যেকোনো শব্দ বা বাক্য সার্চ করা।
8. **স্ক্রিন ওয়েক মোড:** পড়ার সময় স্ক্রিন যাতে হঠাৎ বন্ধ না হয়ে যায় (`expo-keep-awake`)।
9. **ফাইল শেয়ারিং:** যেকোনো PDF ফাইল হোয়াটসঅ্যাপ, ইমেইল বা অন্যান্য অ্যাপে শেয়ার করার সুবিধা (`expo-sharing`)।
10. **ফেভারিট তালিকা:** পছন্দের বইগুলো স্টার মার্ক করে আলাদা ট্যাবে রাখা।

## 📱 কীভাবে আপনার ফোনে এখনই চালাবেন ও টেস্ট করবেন (Testing via Expo Go)

আপনার কোনো প্লে কনসোল অ্যাকাউন্ট ছাড়াই এখনই আপনার ফোনে অ্যাপটি লাইভ দেখার উপায়:

1. আপনার অ্যান্ড্রয়েড ফোনে Google Play Store থেকে **Expo Go** অ্যাপটি ইনস্টল করুন।
2. আপনার কম্পিউটার এবং আপনার মোবাইল ফোন যেন **একই Wi-Fi নেটওয়ার্কে** সংযুক্ত থাকে।
3. কম্পিউটারের টার্মিনালে প্রজেক্ট ফোল্ডারে রান করুন:
   ```bash
   npx expo start
   ```
4. টার্মিনালে একটি **QR Code** আসবে।
5. ফোনের Expo Go অ্যাপ খুলে **"Scan QR code"** অপশন দিয়ে কম্পিউটারের কিউআর কোডটি স্ক্যান করুন।
6. সাথে সাথে আপনার ফোনে **Self PDF Reader** চালু হয়ে যাবে!

## 📦 ফোনে সরাসরি ইনস্টলযোগ্য APK তৈরি করার নিয়ম (Direct Installable APK Build)

গুগল প্লে স্টোরে না দিয়েও সরাসরি বন্ধুদের বা নিজের ফোনে `.apk` ফাইল ইনস্টল করতে চাইলে Expo-র ফ্রি ক্লাউড বিল্ড (EAS Build) ব্যবহার করতে পারেন:

1. EAS CLI দিয়ে লগইন করুন (ফ্রি একাউন্ট):
   ```bash
   npx eas-cli login
   ```
2. প্রজেক্ট কনফিগার করুন:
   ```bash
   npx eas-cli project:init
   ```
3. সরাসরি APK বিল্ড দিন:
   ```bash
   npx eas-cli build -p android --profile preview
   ```
4. বিল্ড শেষ হলে টার্মিনালে একটি ডাউনলোড লিঙ্ক এবং কিউআর কোড দেবে। সেখান থেকে সরাসরি `.apk` ফাইলটি ফোনে নামিয়ে ইন্সটল করে নিতে পারবেন।

## 🚀 ভবিষ্যতে Google Play Store-এ আপলোড করার নিয়ম (Production AAB Build)

ভবিষ্যতে যখন Google Play Console একাউন্ট নিবেন, তখন প্লে স্টোরের জন্য অপটিমাইজড `.aab` বান্ডেল তৈরি করতে রান করবেন:

```bash
npx eas-cli build -p android --profile production
```
এটি প্লে স্টোরে আপলোডযোগ্য সাইন করা `.aab` ফাইল তৈরি করে দেবে।
